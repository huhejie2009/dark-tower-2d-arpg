> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a first playable enemy loop to the 2.5D prototype: enemies chase the player, stop in attack range, can be defeated by test hooks, and unlock the exit when all enemies are defeated.

**Architecture:** Keep this as prototype-scoped behavior inside `Prototype2_5DCombatRoom.gd` so the older 2D tower loop and player saves remain untouched. The scene owns lightweight enemy state dictionaries keyed by enemy node and exposes snapshot/test methods for regression coverage.

**Tech Stack:** Godot 4.6.2, GDScript, headless SceneTree regression tests.
