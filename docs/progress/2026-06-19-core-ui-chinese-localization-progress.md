# 2026-06-19 核心 UI 中文化进度

## 本轮目标

把当前可试玩主线中的核心可见 UI 从英文 / 乱码状态整理为稳定中文显示，并为后续继续做功能、截图 QA 和 GitHub 交接打好基础。

## 已完成

- 主菜单、职业选择、存档槽默认名、职业名完成中文化。
- 主城标题、设施交互、塔前准备摘要、推荐操作和进塔选项完成中文化。
- HUD 中生命、法力、经验、技能点、装备评分、掉落提示完成中文化。
- 背包 / 装备窗口中的筛选、排序、装备部位、稀有度、属性、对比、废品出售 / 分解确认完成中文化。
- 技能节点、技能升级状态、技能摘要完成中文化。
- 掉落通知、死亡结算、楼层目标、清层提示和返回主城提示完成中文化。
- README 从乱码状态重写为正常中文，方便 GitHub 展示和新线程交接。
- 新增中文化回归测试，覆盖主菜单、职业选择、主城、背包装备、掉落通知和死亡结算。

## 验收标准

- 核心 UI 文案不再出现明显英文占位或乱码。
- 新角色默认名、职业显示、装备部位、稀有度、属性名和主要按钮均显示中文。
- 中文化测试通过，避免后续改动把关键 UI 文案退回英文。
- 完整回归通过后，本轮可作为“基础中文化完成”提交。

## 后续建议

- 下一轮优先做实机截图 QA，逐屏检查中文字号、按钮宽度、背包密度和 HUD 遮挡。
- 正式素材接入后再做第二轮 UI 排版，避免临时素材尺寸导致重复返工。
- 长期建议增加统一的本地化表或 `tr()` 接口；当前阶段先完成玩家可见交付体验。
