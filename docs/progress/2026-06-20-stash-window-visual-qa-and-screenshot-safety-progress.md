# 2026-06-20 仓库窗口视觉 QA 与截图工具安全进度

## 本轮目标

继续打磨当前可试玩工程，优先处理实机截图中能直接看到的 UI 视觉问题，并修复 QA 工具自身可能卡死的问题。

## 发现的问题

- 仓库窗口在 1280x720 下过宽，会压到右侧整备面板，导致文字互相穿插，视觉层级很乱。
- 仓库截图里的测试物品和测试角色仍有英文，占位感明显。
- `qa_capture_*_screenshot.gd` 截图工具在 `--headless` 下读取视口纹理会卡住，容易留下残留 Godot 进程。
- 仓库截图工具会创建测试角色；必须保证它和回归测试一样走瞬时存档，不能写入玩家真实存档。

## 已完成

- 缩小并下移 `StashWindow`，让仓库窗口避开主城标题和右侧整备栏。
- 收紧仓库窗口两列列表和说明栏宽度，保留“背包 / 仓库 / 说明”的三栏结构。
- 将仓库截图工具中的测试角色和测试物品改为中文。
- `SaveManager` 新增统一的瞬时存档脚本判定，`tests/regression` 和 `tools/qa_*.gd` 都会走瞬时存档。
- 三个截图工具新增 headless 快速失败保护：截图 QA 必须用带渲染的 Godot 运行，避免视口截图卡死。
- 重新导出仓库窗口截图：`docs/qa/screenshots/town_stash_window_1280x720.png`。

## 新增 / 更新回归

- 新增 `regression_qa_tools_use_transient_save.gd`：确认 QA 工具不写真实存档。
- 新增 `regression_qa_screenshot_tools_headless_guard.gd`：确认截图工具具备 headless 防卡死保护。
- 更新 `regression_stash_window_contract.gd`：确认仓库窗口不遮挡右侧整备栏，并避开主城标题区域。

## 验收标准

- 仓库窗口在 1280x720 下不压右侧整备面板。
- 仓库窗口不遮挡主城标题和副标题区域。
- 仓库截图中不再出现英文测试占位物品名。
- 误用 headless 截图工具时快速退出，不再卡住。
- QA 截图工具不会污染真实玩家存档。
