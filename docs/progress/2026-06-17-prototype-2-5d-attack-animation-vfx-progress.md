# 2026-06-17 2.5D 原型攻击动作与命中特效分离进度

## 背景

上一轮 2.5D 原型已经完成左键攻击、鼠标指向和临时攻击弧，但攻击反馈仍缺少一个关键层次：玩家角色本身没有进入明确的攻击动作状态，命中特效也还没有从人物/武器动画中拆出来。按照后续美术管线规划，人物身体动作、武器层、打击特效必须分离，否则后面做换武器、换职业动作、怪物受击反馈时会互相污染。

本轮继续推进“让游戏先看起来像游戏”的基础链路，但仍不引入正式美术素材，只补可替换接口和灰盒可读反馈。

## 本轮完成

- `BillboardActor3D` 新增动作语义状态：
  - 默认 `idle`。
  - 移动时自动回到 `run`。
  - 战斗场景可显式设置 `attack`。
  - 契约快照新增 `action_state`，方便测试和后续动画播放器接入。
- `Prototype2_5DCombatRoom` 新增玩家攻击动作同步：
  - 攻击被接受时，玩家演员进入 `attack`。
  - 攻击冷却/收束后，根据当前移动输入回到 `idle` 或 `run`。
- 新增独立命中特效节点：
  - `PrototypeHitVfxRoot` 作为场景级 VFX 根节点。
  - `HitImpactMarker` 作为临时命中反馈，不挂在玩家、武器或敌人贴图节点下。
  - `HitImpactMarker` 带有 `vfx_role = "hit_impact"` 元数据，后续可替换为正式贴图序列、粒子或动画资源。
  - 命中后短暂显示，生命周期结束自动隐藏。
- 新增回归测试：
  - `tests/regression/regression_prototype_2_5d_attack_animation_vfx_contract.gd`

## 验收标准

- 玩家未移动时，初始动作状态应为 `idle`。
- 左键命中敌人后，玩家动作状态必须进入 `attack`。
- 命中特效必须由场景级 VFX 节点管理，不能挂在 `PlayerBillboard` 或 `WeaponSprite` 下。
- 命中特效必须带有明确的角色标记 `hit_impact`。
- 命中特效必须出现在被击中敌人附近，并在生命周期结束后隐藏。
- 攻击收束后，玩家动作状态不能长期停留在 `attack`。

## 后续建议

1. 将 `action_state` 从语义字符串升级为正式动画播放器入口，接入 `idle/run/attack/death` 的分方向帧序列。
2. 把 `HitImpactMarker` 替换为正式 VFX 资源清单，区分斩击、钝击、法术命中、暴击和格挡。
3. 增加武器层动作事件：攻击帧期间武器贴图/武器节点播放独立动作，不再生成在人物身体帧里。
4. 在实机 QA 中检查玩家攻击动作、攻击弧、命中特效、敌人死亡反馈是否能在半秒内被玩家读懂。

## 注意

- 本轮不修改玩家存档，不触发真实爬塔进度保存。
- 本轮仍属于 2.5D 原型功能链路，不是正式美术替换。
- 临时命中特效是灰盒可读标记，用于验证时序和分层，不作为最终资产。
